# Contributing

Read [HANDOFF.md](HANDOFF.md) and the relevant specification before changing behavior.
Contributions must be material you have the right to offer under MIT OR Apache-2.0.

## Private information

Use synthetic data in tests, examples, screenshots, and issue reports. Do not commit research
measurements, participant information, customer information, instrument exports, credentials,
license keys, private settings, or machine-specific user paths. An ignore rule does not remove
anything already committed: inspect staged changes and history before publication.

## Independent implementation and provenance

Describe behavior and file formats in your own words and record the source of each observation.
Do not copy or translate proprietary source, decompiled output, vendor artwork, templates,
sample projects, or documentation into the project. Review the applicable license/terms before
using a proprietary product or other implementation for reference. Public availability alone
does not grant reuse rights.

Keep notices for any third-party material and add assets to [ATTRIBUTION.md](ATTRIBUTION.md).
Do not claim a formal clean-room process unless its separation and provenance are documented.

Local optional tests against an installed Origin copy use `ORIGIN_HOME` for the installation
folder. These tests do not require vendor files to be stored in the repository.
